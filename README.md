# Algory QI — Fall 2026 starter code

Starter files and self-checks for the Quantitative Investments education
sessions. The assignments themselves go out by email each week.

## Files

- `hwNN_starter.py` — a skeleton with the functions the assignment asks for,
  each one empty. Fill them in.
- `check_hwNN.py` — runs your starter file and tells you which parts are
  wrong. Put it in the same folder as your starter and run
  `python check_hwNN.py`.
- `_check.py` — shared by the checkers. Keep it alongside them.

## Getting all of it

Code button above, then Download ZIP. Or:

    git clone https://github.com/WilliamANeild/algory-qi-f26-starter.git

## What you need installed

    pip install yfinance pandas numpy matplotlib scikit-learn

The checks are not graded. They exist so that being stuck at 11pm is a
solvable problem.
